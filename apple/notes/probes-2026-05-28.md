# M4 Pro CPU Probe Smoke Run - 2026-05-28

Command:

```sh
make -C soc-microarch/apple run-smoke
```

Observed host:

- Apple M4 Pro
- 14 logical CPUs: 10 performance, 4 efficiency
- P-core L1I/L1D: 196608 / 131072 bytes
- E-core L1I/L1D: 131072 / 65536 bytes
- SME available

First smoke-run signals:

- `CNTFRQ_EL0` reports 1 GHz, so timer ticks map directly to nanoseconds.
- QoS-hinted dependent add showed `user_interactive` faster than `background`
  in this run: about 0.297 ns/op vs 0.479 ns/op.
- Dependent smoke-loop medians:
  - `dep_add`: about 0.479 ns/op
  - `dep_mul`: about 1.304 ns/op
  - `dep_fadd`: about 0.587 ns/op
  - `dep_fmul`: about 0.833 ns/op
- Pointer-chase sweep stayed flat through 128 KB, then jumped at 256 KB in this
  run. That lines up with the exposed P-core 128 KB L1D size and is a good
  early sanity check.

These are smoke-run numbers only. Full runs with more samples, pinned workload
conditions, and overhead correction are needed before turning them into a
microarchitecture table.
